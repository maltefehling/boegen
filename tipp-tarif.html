Tipp: Grundgebühr und Preis pro km

Beispiel mit anderen Zahlen:
Taxi A: 3 € Grundgebühr + 2 € pro km
Taxi B: keine Grundgebühr, 2,50 € pro km
A:  y = m · x + c
B:  y = 2,5 · x + 0 = 2,5x
Merke: Grundgebühr / Startwert (das, was man bei x = 0 schon zahlt) → c, steht hinten.   „pro km“, „pro Minute“, „pro Stück“ (das, was jedes Mal dazukommt) → m, steht vor dem x.
Keine Grundgebühr → c = 0, die Gerade startet im Ursprung.  Wo sich die Geraden kreuzen, sind beide gleich teuer → gleichsetzen.
